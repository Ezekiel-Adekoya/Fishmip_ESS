## 2. Script 02 — the one to look at first

Two faults, and the second is the dangerous kind.

**`plankton_all` was never built.** The processing chunk returns one *wide*
table per group (`Year` + a column named after the group). The spin-up chunk
expects a single *long* table with `Year / val / variable`. Nothing bridged
them, so the chunk died on its first line and the 1861–2010 plankton files were
never produced. That is why 04's committed `.dat` existed but could not be
regenerated — the inputs were gone.

**`file_label` matched nothing.** It was keyed on the long names
(`Diatoms`, `Diazotrophs`, …) while `variable` carries the short ones
(`Diat`, `Diaz`, …), so every `filter()` returned zero rows.

Fixing only the first fault would have made 02 run **without error** and write
five empty CSVs. I added `stopifnot()` on the key set and a row-count and
contiguous-year check per file so that cannot recur.

## 3. Script 04 — the resource level (the substantive change)

The COBALT-derived resource, measured against the resource
`params_stage1_steady` was calibrated on, over the bins the model actually sees
(`w < w_pp_cutoff`):

| size band | before | after anchoring |
|---|---|---|
| < 0.001 g | ×4.59 | ×0.94 |
| 0.001–1 g | ×5.89 | ×1.21 |
| 1–4.19 g | ×7.23 | ×1.49 |
| 4.19–100 g | ×8.10 | ×1.67 |
| **total** | **×4.96** | **×1.02** |

This is not a fault in your spectrum construction — per-group biomass
conservation is exact to 6e-15, and a semi-chemostat resource tuned to balance
a fish community is not a prediction of plankton standing stock. The problem is
that the fish were calibrated against the lower level, so the ESM level
invalidates the calibration.

**Measured consequence.** A 100-year projection at mean 1861–1960 effort with
the resource held constant:

```
calibrated resource      B(0) 6.52  B(100y)  7.45 g/m2   drift x1.14
GFDL 1861, UNANCHORED    B(0) 6.52  B(100y) 32.74 g/m2   drift x5.02
GFDL 1861, ANCHORED      B(0) 6.52  B(100y) 10.00 g/m2   drift x1.53
```

The unanchored case reproduces what your 05 outputs actually show (36.9 g/m²
at 1961), so the mechanism is confirmed. Note ×1.14 of the residual ×1.53 is
the base model responding to spin-up effort differing from `initial_effort`,
not the resource.

**The fix** is one constant multiplicative factor (×0.206) applied to every
year and every bin, set so the 1978–1981 resource biomass below the cutoff
matches the calibrated resource. Being constant it is additive in log10, so it
cannot touch the slope or the year-to-year variation — both are asserted in the
script. `GFDL_resource_slope.dat` is unchanged; the intercept shifts by the
same constant.

This is a modelling judgment, not a bug fix, which is why it is in its own
commit (`a25138e`) — take it or argue with it independently of the rest.
The alternative would be to recalibrate the fish against the ESM resource.

**Left deliberately alone:** `fit_slope()` fits over every bin with
`dens > 0`, which includes the 55 extension bins it generated itself at exactly
slope `b`. So the self-consistent `b` is partly fitted to its own extrapolation
across 4.4 decades of size. This biases the *slope*, not the level, so it does
not affect the anchor — but it is circular and worth a look. I did not change
it because it would move `b` and that is your call.

The residual ×1.67 in the 4.19–100 g band is your deliberate extension standing
in for prey COBALT does not report. Now the largest remaining discrepancy.

## 5. Script 05 — what was wrong with it

**It has now been run** with `n_sims = 1` on the anchored forcing, and
`Fishmip_output/` and the two `sims_*.RDS` files are regenerated. Section 9
below has the results.

**The cache will silently hand you stale results.** The guard is
`if (file.exists(cache_f) && file.exists(cache_c) && !exists("force_resim"))`,
so it cannot tell that the forcing changed under it — before this run the cached
sims were 46 minutes OLDER than the spectra they were supposedly built from.
Whenever you change params, effort or forcing, **set `force_resim <- TRUE`
before the cache chunk** (deleting the RDS files does not work in a Dropbox
folder — Dropbox restores them within seconds). Worth making the guard compare
file mtimes against its inputs.

**Two objects were used but never defined**, so the script could not reach its
end on any machine:

- `base_dir` was hardcoded to `/Users/ezekieladekoya/...`, and the very next
  line is `stopifnot(dir.exists(base_dir))`. So the whole export section — every
  FishMIP output file — stopped there for anyone else. Now `here::here()`, like
  every chunk before it. (README issue 4 is therefore *not* resolved; I had
  said "largely resolved" from reading the earlier chunks, which was wrong.)
- `catch_ts` is read by the pelagic catch, demersal catch and size-class catch
  sections, but nothing ever built it — `object 'catch_ts' not found`. It is the
  wide form of `yield_ts`, so it is now derived from `yield_ts` where that is
  loaded, which keeps the per-group catch consistent with total catch (tc).

**`n_sims` was 10**, not 1 as the README says. Set to 1 at Julia's request for
a calibration check.

**`biomass_ts.RDS` is generated by a new script.** It was missing. The copies in
the sibling ESS repos are all identical and none is usable: 13 species under raw
upper-case survey names (`AMERICAN PLAICE`, `HERRING(ATLANTIC)`), including
Greenland Halibut, which is not in the model — they fail 05's own check that the
three pelagic species are present by name. The copy in
`Thermizer/August_2025/Ess_Thermizer_data/` is unreadable, possibly corrupt.

So `make_biomass_ts.R` rebuilds it from `LF_Biomass_Abund.csv`, reproducing 05's
own construction step for step (4VsW strata 443–466, 1970–2024, kg→g). Forage
catchability multipliers **are** applied (Herring ×50, Sand Lance ×3000,
Capelin ×200) — Julia's decision. Be aware this means `tpb` is compared against
survey values inflated up to 3000-fold. Those multipliers were tuned to balance
seal predation, not derived as catchability estimates. The script has an
`apply_forage_multipliers` flag if you want raw survey values instead.

**A column-name disagreement worth reconciling.** 05 builds the same survey
table internally around line 419 and renames the value column to `Biomass_Obs`,
but everything after the "Survey data" step (`obs_tcb`, `pel_obs_all`,
`obs_tdb`) sums a column called `Biomass`. So the `readRDS` is load-bearing
rather than redundant, and the two halves of the script disagree. One of them
should change.

## 6. Calibration check (`calibration_check.R`, Julia's script)

Worth recording because it tells you where *not* to look:

- Yields within 7% of target for 16/19 species
- Biomass within 2x for 15/19 — low: White Hake 0.27x, Thorny Skate 0.34x,
  Red Hake 0.42x, Longhorn Sculpin 0.47x
- All `erepro` < 1
- **Stable over 100 years at constant effort: all 19 species within 5%, none
  still moving**

So the catch overshoot is *not* a base calibration failure and not drift in the
calibrated state. That is what pointed at the forcing.

Against observations, before the anchor, modelled catch was high in every
decade — 2.7x (1970s), 3.2x (1980s), 3.8x (1990s), 2.3x (2000s), with spikes at
1981 (17x), 1989 (11x), 1999 (12x). Roughly flat rather than growing, which is
what ruled out progressive drift. Expect ~1.3–1.5x after anchoring, not 1.0.

| variable | unanchored (committed) | anchored (new) | change |

**The ÷3.33 on catch is the point.** Before anchoring, modelled catch ran
2.7–3.8x over observations by decade (§6). The anchor removed almost exactly
that factor, which is the strongest evidence that the resource level was the
cause rather than something that merely correlated with it.

### Agreement with observations, after anchoring

`log10(median obs/sim)`; 0 is perfect, positive means the model is **under**
observations.

| | log10 | ratio | reading |
|---|---|---|---|
| **tc** total catch | **+0.06** | obs ×1.15 | within 15% |
| **tdc** demersal catch | **−0.02** | sim ×1.05 | essentially exact |
| **tdb** demersal biomass | −0.24 | sim ×1.7 | good |
| cd90cm | −0.22 | sim ×1.7 | good |
| cd30to90cm | +0.31 | obs ×2.0 | fair |
| bd30to90cm | +0.28 | obs ×1.9 | fair |
| bd90cm | −0.62 | sim ×4.2 | too many large demersals |
| **tpc** pelagic catch | +0.65 | obs ×4.5 | **under-predicted** |
| tcb total biomass | +0.63 | obs ×4.2 | multiplier artefact, see below |
| tpb pelagic biomass | +2.89 | obs ×776 | multiplier artefact |

Catch is now the best-constrained thing in the model, which is the right outcome
— it is what the effort series and catchabilities were fitted to.

**The two big-looking misfits are not model error.** `obs_exclude` is
`character(0)`, so observed tcb sums all 19 species *including* the forage
catchability multipliers (Herring ×50, Sand Lance ×3000, Capelin ×200). Measured
over the 41 overlapping years:

```
observed tcb, all 19 species      34.16 g/m2   -> obs/sim x4.24
observed tcb, 3 forage excluded    5.04 g/m2   -> obs/sim x0.55  (sim x1.8)
simulated tcb                      8.41 g/m2
the 3 forage species are 85.3% of the observed total
```

So 85% of the "observation" is multiplied sand lance, and tpb's ×776 is just
×3000 diluted. Excluding them puts total biomass at sim ×1.8, consistent with
tdb's ×1.7. **Decide what the multipliers are for before quoting tcb or tpb
against observations** — as it stands those two rows compare the model to a
calibration assumption, not to data.

**Pelagic catch is the real remaining mismatch.** `catch_ts` comes from
`yield_ts`, which has no multipliers at all and which drops Sand Lance and
Capelin, so tpc is essentially herring catch alone — under-predicted ×4.5. That
one is worth chasing.

**The trajectory shape is right.** tcb falls 12.35 → 8.09 g/m² over 1961–2010
and tc falls 2.36 → 0.09, which is the groundfish collapse. The model was not
just too high before, it is now declining for the right reason.

### What is still unverified

- **`n_sims = 1` means there is no ensemble spread**, so every `sim_lower` /
  `sim_upper` band in the figures is a single line and the `tcblog10` /
  `tclog10` "first simulation only" shortcut is invisible. Raise `n_sims` before
  reading anything as an uncertainty range.
- These numbers are medians over the overlapping years, not a fit. Nothing here
  was tuned to them.

## 11. Recalibrating against the COBALT resource

Julia asked for the alternative to the level anchor: build a new therMizer
object, fit the fish to the resource COBALT actually reports, run the long
series, and see whether it still passes through the observed catch and biomass.
Scripts 06, 07 and 08 do that. **It works**: the recalibrated model runs
1861-2010 on the raw COBALT resource with no anchor and stays near the observed
biomass level.

**Two mistakes of mine on the way, recorded so they are not repeated.**

1. An earlier version of this section said this route "cannot work" because
   `steady()` does not find the model's attractor. That was a bug in my script:
   I attached the COBALT forcing array but never set the model's own resource
   state to it, so `steady()` fitted the fish to Stage 1's old resource (a fifth
   of COBALT) and the fish jumped when `project()` swapped the real one in.
2. I then calibrated on 1970-2010 averages. Julia corrected this to
   **1978-1981**, the years the previous calibration used, and that turned out
   to matter enormously (below).

Julia's framing is the one to keep: the steady state is an initialisation that
captures a time-averaged state, `steady()` and `matchBiomasses()` need constant
time-averaged inputs, and the dynamic run is not expected to stay at
equilibrium.

### The calibration (06)

Starts from `params_stage1_steady.RDS`, so species, gears and the interaction
matrix are unchanged and only the resource differs. Three inputs are held
constant at their **1978-1981 mean**:

- the model's resource state, at the unanchored COBALT spectrum (04 now writes
  that file next to the anchored one), with `resource_constant` dynamics;
- temperature, 6.66 / 4.03 C;
- effort, gear by gear (this reproduces Stage 1's `initial_effort`).

The targets in `species_params` are 1978-1981 averages too: per species they
match that window far better than 1970-2010 (7/19 biomass and 9/16 yield within
5%, against 2/19 and 0/18).

`calibrateBiomass()` is deliberately not used, because it rescales the resource
along with the fish. The script asserts at the end that the resource is still
exactly the COBALT spectrum.

```
total biomass        6.491 g/m2
biomass within 2x    19/19 species, median ratio 1.012
yield within 2x      15/16 species, median ratio 1.157
erepro               all below 1 (max 0.383)
```

`matchYield()` errors on this model and is skipped; in an earlier run it
diverged outright, so 06 only keeps a matching step if it improves the fit and
stays admissible.

### The dynamic run (07)

```
1861    6.49 g/m2
1961   10.01      (spin-up change x1.40)
1980    6.41
2010    6.02
```

Scored as Ortega-Cisneros et al. (2025, Earth's Future) step 6 asks -- bias and
correlation of catch and biomass time series -- for the 16 species without
survey multipliers. The paper also says 2005-2010 catch must not be used in
calibration because it is held back for predictive skill; the calibration here
uses 1978-1981 only, so those years are a genuine out-of-sample test.

| | species | median bias (mod/obs) | within 2x | median correlation |
|---|---|---|---|---|
| catch, 1970-2004 | 15 | x1.07 | 9 | +0.54 |
| catch, 2005-2010 (held out) | 11 | x0.74 | 1 | +0.13 |
| biomass, 1970-2004 | 16 | x1.04 | 12 | +0.23 |
| biomass, 2005-2010 (held out) | 16 | x0.90 | 4 | +0.02 |

Summed over those 16 species, modelled annual catch over 1961-2010 is within 1%
of observed (median observed/modelled x1.01). So the level of both biomass and
catch is right, and in-sample catch correlation is reasonable.

**Catch here means fishery catch only.** Seals are a gear in this model, so
`getYield()` counts what seals eat as catch. An earlier version of these
numbers did that and showed catch 2.7x too high in 2005-2010; by then seal
predation is 91% of the "yield" of haddock and 98% for American plaice. 06 and
07 now sum the four fishing gears only, as 05 does. Anything else that calls
`getYield()` on this model needs the same care.

### What does not fit, and why

**1. Cod does not collapse.** Observed cod biomass after 1993 is 13% of its
1978-1981 level; modelled cod keeps rising and is 9.5x observed over 1994-2004.
Modelled cod catch (trawl only) is about 30x observed in that period.

**2. Effort is per gear, the 1993 moratorium was per species.** Bottom-trawl
effort falls 20-45x after 1993, but observed cod landings fall about 200x, to
roughly 430 t a year. Haddock shows the problem cleanly: its modelled biomass is
right (0.83x observed, 1994-2004) but its trawl catch is about 10x too high. A
fleet-level effort series cannot represent a closure on one species. This is
why only 1 of 11 species is within 2x in the held-out years even though the
median bias is modest.

**3. Forage fish go the wrong way.** This is not really a model collapse:

- 1978-1981 is the low point of the (multiplied) survey series for all three.
  Herring is 8.6e9 g then, 6.6e10 before and 3.7e12 by 1996-2010. So the model
  is initialised at the bottom of the observed forage series.
- In the model they then fall further, to 12-15% of the start by 2010 and
  capelin to zero. The Seals gear has catchability 8.26 on all three and seal
  effort rises from 0.024 (1980) to 0.875 (2010), which scales to a seal
  mortality of about 0.2 per year in 1980 and 7 per year in 2010.
- In the survey they rise by two to three orders of magnitude after the early
  1990s.

Points 1 and 3 are probably one problem. On the Scotian Shelf the forage
increase followed the groundfish collapse; a model in which cod never collapses
has no predator release, and meanwhile seal mortality on forage climbs
unchecked. That link is my reading, not something tested here.

Things that would be worth trying, none attempted:

- species-specific effort or catchability after 1993 for the moratorium stocks;
- capping or re-deriving the seal mortality on forage, which was tuned together
  with the survey multipliers (§5);
- error sampling around the initial state, as Julia suggested.

### Which input moves it (08)

Starting from the calibrated state and releasing one input at a time:

```
total biomass, g/m2                 1861    1870    1961    2010
A  all constant                     6.49    6.53    6.51    6.50
B  only effort varies               6.49    8.57    9.95    6.04
C  only temperature varies          6.49    6.57    6.56    6.45
D  only resource varies             6.49    6.53    6.50    6.51
```

The calibrated state holds for 150 years under constant inputs. Resource and
temperature variability barely move it; effort does nearly everything.

**Why 1978-1981 and not a longer average.** The Seals gear:

```
                  Bottom_Trawl  Fixed_Gear  Small_Mesh  Pelagic  Seals
1978-1981             0.879       0.579       0.097      0.442   0.023
spin-up 1861-1960     0.639       0.732       0.047      0.522   0.004
1970-2010 mean        0.563       0.529       0.124      0.511   0.278
```

Calibrating on the 1970-2010 mean balanced the fish against seal mortality that
did not exist in the early years. In that version case B reached 125 g/m2 by
1961 and catch was about 8x observed. Raising reproduction levels did not fix
it (still x7 at 0.99, with `erepro` above 1).

### Where this leaves the two routes

Both now give a model at about the right level for biomass and for total catch
(anchored: total catch within 15%, §9; recalibrated: within 1% for the 16
species without multipliers). The recalibrated one is the more defensible
construction, since the fish are consistent with COBALT's resource by
construction and no anchor is needed. Neither reproduces the cod collapse, the
moratorium or the forage increase, and those are structural rather than a
matter of which resource level is used. The two have not been compared species
by species on identical metrics.

## 13. Reproduction level (resilience to fishing and predation)

Julia's suggestion: the species look too resistant to fishing and predation, so
look at the reproduction level. Tested on the recalibrated model of §11.

**The calibrated levels are indeed very high.** 16 of 19 species sit above 0.9

## 14. Adult natural mortality is the missing lever

Follow-up to §13. If the species are too resistant but reproduction level is
not the cause, what is? Breaking mortality down by source for mature fish in
the dynamic run of §11 answers it:

| mature fish, per year | fishing 1980 | fishing 2008 | seals | predation | background | total 2008 |
|---|---|---|---|---|---|---|
| Atlantic Cod | 0.290 | 0.001 | 0.000 | 0.000 | 0.022 | 0.023 |
| Thorny / Winter Skate | 0.013 | 0.000 | 0.000 | 0.000 | 0.025 | 0.025 |
| Monkfish | 0.003 | 0.000 | 0.000 | 0.000 | 0.023 | 0.023 |
| Haddock | 0.188 | 0.001 | 0.007 | 0.010 | 0.041 | 0.058 |

**Adults in this model have almost no natural mortality.** The seal gear takes
no mature cod (its size kernel sits on small fish), predation on adults is nil,
and the background rate is mizer's allometric default (`z0`), which is 0.02-0.04
per year for these species. Once fishing stops, an adult cod dies at about 2% a
year, so the stock cannot stay down. Stock assessments conventionally use 0.2.

Modelled cod fishing mortality is right, incidentally: 0.290 in 1980 against an
observed catch/biomass of 0.316, and 0.215 against 0.240 in 1990.

**Temperature does not touch this.** therMizer 1.1.0 scales predator search
volume (so encounter and predation mortality) and metabolism with temperature.
It has no mortality method, so background mortality is constant, as is fishing
mortality.

### Test: raise background mortality, recalibrate, project

Same procedure as 06 with `ext_mort` raised to at least 0.2 per year, either
for every species or only for five whose modelled trend was flat (cod, white
hake, winter skate, monkfish, pollock). All three calibrate equally well at
steady state (19/19 species within 2x on biomass, 15/16 on yield).

| | as calibrated | M >= 0.2, all | M >= 0.2, five species | observed |
|---|---|---|---|---|
| cod 1994-2004 relative to 1978-81 | 1.62 | 0.69 | 0.68 | 0.13 |
| cod trend, log10 per decade | +0.08 | -0.14 | -0.14 | -0.25 |
| cod correlation with survey | -0.50 | +0.49 | +0.49 | |
| biomass 1970-2004: bias, within 2x | x1.04, 12/16 | x0.80, 12/16 | x0.99, 13/16 | |
| biomass 2005-2010: median log10 RMSE | 0.87 | 0.91 | 0.66 | |
| catch 1970-2004: within 2x | 9/15 | 11/15 | 10/15 | |
| species better / same / worse (RMSE) | | 7 / 4 / 8 | 12 / 7 / 0 | |
| total biomass 2010, g/m2 | 6.02 | 1.76 | 2.66 | |
| max `erepro` | 0.383 | 1.24 (dogfish) | below 1 | |

- Raising it for everything overshoots: plaice, yellowtail, haddock and dogfish
  were already falling too fast and fall faster, and dogfish cannot sustain it.
- Raising it for the five improves 12 species and worsens none. Cod now
  declines after the moratorium and correlates with the survey (+0.49 from
  -0.50); winter skate RMSE goes from 0.66 to 0.37. Species not in the five
  improve too (redfish, yellowtail, witch flounder, sculpin), presumably through

- Cod still only falls to 0.68 of its 1978-81 level against 0.13 observed, and

**Caveats.** The five species were chosen by looking at the fit, so this is a
demonstration that the lever works, not an independent test. The value 0.2 is
the textbook default, not an ESS estimate. Proper next step: species-specific
natural mortality from the assessments, and for cod a mortality that rises
after 1990. These were scratch runs; nothing in 06 or the saved params was
changed.

## 15. Does the starting state affect the fit?

Julia's question: should each species' initial abundance carry a multiplier,
and do different initial states change the goodness of fit to the time series?
Tested on the model of §11 as calibrated (without the raised mortality of §14).

**The 1861 start is forgotten.** Scaling the whole community's starting
abundance and running the full series:

| start at 1861 | total biomass relative to the unscaled run: 1870 | 1900 | 1961 | largest single-species difference at 1961 |
|---|---|---|---|---|
| x0.1 | 0.72 | 1.01 | 1.002 | 11% |
| x0.5 | 0.88 | 1.01 | 1.001 | 4% |
| x2 | 1.22 | 0.98 | 0.997 | 11% |
| x10 | 2.99 | 1.04 | 0.956 | 94% |

The community total converges within about 40 years, so a multiplier on the
1861 state cannot change the fit over 1970-2010 except for the slowest species
under an extreme start. What matters is the state at the start of the data
period, which the 100-year spin-up sets.

**Varying each species at 1961, one at a time** (x0.1 to x10, 114 runs from
the spun-up 1961 state; a x1 restart reproduces the full run to 4e-16):

- How long a species remembers its start differs enormously. After a x4 start,
  silver hake, pollock, redfish, witch flounder, herring and sand lance are
  back to the unscaled run by 1970. Cod and haddock are back by 1980. Thorny
  skate, winter skate and monkfish are still x2.1 to x2.3 in 2000, and dogfish
  x1.4.
- The fit barely responds. Only five species improve their own biomass RMSE by
  more than 0.05 at their best multiplier: thorny skate (0.61 to 0.51 at
  x0.25), winter skate (0.66 to 0.57 at x0.25), monkfish (0.96 to 0.89 at
  x0.25), dogfish (0.83 to 0.74 at x10) and red hake (0.83 to 0.77 at x0.1).
  Cod is unchanged at 0.66 whatever its start.
- For the skates and monkfish the improvement is a level shift, not a better
  trajectory: a lower start sits closer to the later low survey values, but
  their catch fit gets worse (thorny skate 0.74 to 1.01, winter skate 0.80 to
  1.04, monkfish 0.84 to 1.06).
- The community median RMSE moves from 0.618 to 0.59 at best.

**So a per-species initial multiplier is not worth adding as it stands.** Most
species forget their start within one or two decades, and the few that remember
it do so because they have almost no adult mortality (§14): the long memory of
the skates and monkfish is the same symptom as their flat trend. With a
realistic adult mortality their memory would shorten and the starting state
would matter even less. Scratch runs; nothing in the repo's model files
changed.

## 17. The seal gear: too strong after about 1990 for everything except cod

Follow-up to §16, on the model with estimator-based adult mortality.

**What the gear does.**

- It selects fish of roughly 90-480 g (Gaussian in log weight, peak near 190 g;
  0.7% at 2 kg). For cod that is juveniles only; mature cod get none.
- Catchability is 8.26 for most species (skates 1.65, monkfish and dogfish
  0.83, halibut 0).
- Its effort is exactly proportional to the logistic seal abundance series from
  1978 on: 7.6 thousand seals in 1980, 275 thousand in 2010, a 36-fold rise.
- So the mortality RATE on juveniles in the size window rises 36-fold too,
  with no limit: 0.03-0.15 per year in 1980, 1.1-2.8 in 2000, 2.6-4.3 in 2010
  (cod 2.63, haddock 3.73, yellowtail 3.57, sculpin 4.31).
- What it removes per seal falls from 3.0 t a year in 1980 to 1.2 t (1990),
  0.7 t (2000) and 0.2 t (2010). The rate keeps rising while the amount each
  seal gets collapses. That is a predator with no saturation eating down its
  prey, not a ration.

**Test.** Six seal-effort trajectories, all equal to the original in 1978-1981
so the calibration state is untouched, differing only in how far effort rises

- Held-out catch is over-predicted about 2x in every weaker variant. That is

- The forage fish fall under every variant.

for Julia and Ezekiel to choose between: cap or saturate the effort series;

late-period level (no collapse of everything after 2000), and the direction of
the forage fish, which rise instead of falling (though by one to two orders of
magnitude, not the two to four in the multiplied survey).

**What it gets worse:** catch. In-sample catch is 1.45x too high with 7 of 15
species within 2x (gear model 0.90x, 11 of 15), and 2.7x too high in 2005-2010.
Monkfish still does not decline. Seal numbers rise too fast early (63 thousand
in 1985 against 18) and too slowly late (182 thousand in 2010 against 280).

**Three cautions before reading this as "dynamic seals are better".**

1. **It is not a like-for-like test of the seal representation.** The Paper 2
   model also has a cod `R_max` cap, forage `R_max` boosted 8x, forage fish
   preying on juvenile groundfish, herring catchability cut to 5%, and fishing
   catchabilities optimised against these same time series. It has no
   temperature or COBALT forcing, uses the Stage 1 resource, and does not have
   the adult mortality of §16.
2. **In that model the seals themselves kill very little.** Seal predation on
   juvenile cod is 0.01 per year in 1980 and 0.11 in 2010; on haddock 0.007.
   The gear imposes 2.6 and 3.7. So the cod collapse there comes from the other
   structural changes, not from the seals, and the main thing the dynamic seal
   contributes is NOT wiping out the juveniles of everything else.
3. **2005-2010 is not held out for it.** Paper 2's catchabilities were
   optimised on series running to 2024, so its 2005-2010 scores are in-sample.
   The gear model's are genuinely out of sample.

**What follows for FishMIP.** The comparison supports replacing the seal gear,
and suggests the features worth carrying over are the saturating seal predation
and whatever makes cod stay down (the `R_max` cap and the forage-on-juvenile
terms), tested one at a time on the FishMIP model so each can be justified.
Moving the whole Paper 2 model across would also need therMizer attached, its
longer resource grid regenerated in 04, a seal state for 1861-1960, and its
catch fit repaired.

**Only the seal cap does anything.** It repeats the result of §17: ten species
improve, held-out biomass RMSE goes from 0.77 to 0.26, and cod gets worse
because it recovers. Features 2 and 4 change nothing at all. Features 3 and 5

together is just the seal cap again.

**Why the others do nothing: the Paper 2 mechanism is a chain, and here it
never starts.** In Paper 2 the cod collapse runs: forage fish become abundant,
forage fish eat juvenile cod, cod stays down. In the FishMIP model the forage
fish are calibrated to their 1978-1981 survey values, the lowest in the series,
and the seal gear then drives them lower. There are too few of them to eat
anything.

A follow-up run confirmed that it is the scale of the forage fish and not only
the seals. All five features, with the seal gear taking progressively less
forage:

| | forage biomass in 2000, g/m2 | herring / sand lance / capelin, 1994-2004 rel. to 1978-81 | predation on juvenile cod, per year | cod |
|---|---|---|---|---|
| seals eat forage as before | 0.012 | 0.30 / 0.03 / 0.01 | 0.040 | 1.07 |
| seals take 5% of forage | 0.38 | 1.67 / 2.81 / 0.87 | 0.040 | 1.07 |
| seals take no forage | 0.47 | 1.85 / 3.41 / 1.05 | 0.039 | 1.07 |

| multiplied survey | 705 | 487 / 278 / 17400 | | 0.13 |

then right. But they reach under 1 g/m2, predation on juvenile cod does not
move, and cod does not respond. The multiplied survey has forage at 705 g/m2
in 2000, more than a hundred times the rest of the community put together,
which is the multiplier question of §5 and §9 again. In the Paper 2 run herring
alone is about 10-20 g/m2 by 2000.

**So the Paper 2 features cannot be carried over piecemeal.** They work there
as a package that depends on forage fish being abundant, which in turn depends
on the starting forage level and on what the multipliers are taken to mean.
For the FishMIP model the choices are:

1. keep seals as a gear but saturate it (the cap), and give cod its own extra
   mortality after 1990, accepting that forage fish are not reproduced;
2. settle the forage level first (what biomass herring, sand lance and capelin
   should have in 1978-1981 and after), then revisit the cultivation terms;
3. move to the Paper 2 model as a whole and attach the climate forcing to it.

These were scratch runs; no model files changed.

## 20. Dynamic seals built on the FishMIP model: it runs, and it does not fit

Julia asked for the seal gear to be replaced by a dynamic seal species on the
FishMIP model. This was built and run. Working scripts are in
`dynamic_seal_trial/` (not cleaned up; see its README), figure in
`figures_recalibrated/dynamic_seal_trial.png`. The model files used by 06-09
were not changed.

### What was built

- The Seals gear and its effort column removed; four fishing gears remain.
- Grey Seal added as a species with Paper 2's parameters (16-300 kg, `h` 390,
  prey-size preference `beta` 15000) and Paper 2's prey preferences: sand lance
  1.0, cod 0.55, plaice / yellowtail / witch 0.14, all other fish 0.04.
- The size grid extended from 100 to 106 bins (to 337 kg) with the original
  bins preserved exactly. Every fish rate in the rebuilt model (search volume,
  intake, metabolism, background mortality, maturity, selectivity,
  catchability) is identical to the calibrated one.
- Outside food for the seal as in Paper 2, about 43% of its maximum intake.
- COBALT spectra padded for the six new bins (they are above the resource
  cut-off, so nothing changes), and the exposure and vertical-migration arrays
  given a seal entry.
- **Temperature.** Seals are endotherms and therMizer cannot exempt a species.
  The seal is given a very wide thermal range (-50 to 80 C), which makes the
  scaling nearly flat, and its search volume and metabolism are divided by the
  scaling at the reference temperature. What is left is a spurious sensitivity
  of about +/-3.5% in search volume and +/-20% in metabolism across 3-7.5 C.
- Calibrated at the 1978-81 seal number (15 thousand, digitised series), fish
  re-matched: all 19 fish within 2x on biomass, 15/16 on yield.
- Projection in two phases: seals held near their 1960 number (2 thousand)
  through 1861-1960, then free to grow from 1961 with Paper 2's `R_max` 8100.

### The key finding: what the seal eats

At the calibration state the Paper 2 seal takes 43 kt a year (2.85 t per seal),
of which 29 kt is the **plankton resource**, 13 kt outside food, and under
1 kt fish. It is allowed to feed on the background resource and its prey-size
preference puts a 150-300 kg seal on 10-100 g resource. So as specified it is
almost decoupled from the fish. That is also why seal mortality was so small
in the Paper 2 run of §18.

Two versions were therefore run:

- **A, as Paper 2.**
- **B, eats fish and outside food only**, with its search volume scaled so
  15 thousand seals take about what the old gear removed around 1980 (21 kt a
  year achieved against a 22.5 kt target). Sand lance cannot sustain this at
  its calibrated biomass (`erepro` 13.4); every other fish stays admissible.

### Results, 16 species without multipliers

| | seal gear | dynamic A | dynamic B |
|---|---|---|---|
| biomass 1970-2004: bias, within 2x, median r | x0.90, 12/16, +0.36 | x1.36, 12/16, -0.25 | x1.32, 13/16, -0.20 |
| biomass 2005-2010 (held out): bias, RMSE | x0.28, 0.77 | x3.07, 0.56 | x3.01, 0.49 |
| catch 1970-2004: within 2x, RMSE | 11/15, 0.52 | 8/15, 0.70 | 9/15, 0.72 |
| cod 1994-2004 rel. to 1978-81 (observed 0.13) | 0.64 | 2.08 | 1.57 |
| total fish biomass 2010, g/m2 (survey ~4) | 1.84 | 16.4 | 13.7 |

Seal numbers (thousand), identical in A and B:

| | 1961 | 1970 | 1980 | 1990 | 2000 | 2010 |
|---|---|---|---|---|---|---|
| digitised | 2 | 5 | 15 | 38 | 155 | 280 |
| model | 2 | 66 | 122 | 166 | 200 | 226 |

**Neither dynamic-seal version fits.** Once fishing collapses the fish balloon
to three or four times the survey, cod rises instead of collapsing, and in-sample
correlation turns negative. It behaves like the "seal mortality held flat"
case of §17. Two separate reasons:

1. **The seals do not eat enough fish to matter.** Even in version B, scaled to
   the gear's 1980 removal, feeding saturates as seals multiply, so predation
   does not keep pace with a fifteen-fold rise in seals.
2. **The seal trajectory is wrong.** The model's seals grow fastest at the
   start and flatten; the real population grew slowly until about 1990 and then
   steeply. Their numbers are the same in A and B, so they are set by the
   seal's own parameters and outside food, not by fish. Paper 2 calibrated its
   trajectory from 1978 (its script 25); starting free growth in 1961 exposes
   that the demography is not right over the longer period.

So the two representations bracket the truth: the gear kills far too much after
1990 (§17), these dynamic seals far too little. The version that fits best is
still the gear with its effort saturating at about the 1990 level.

### What a dynamic seal would need to work here

- a seal growth curve calibrated to the counts over 1961-2010, not just from
  1978 (or seal numbers prescribed from the counts, which is what the gear
  effectively does);
- feeding on fish, not on the resource, with a ration that means something
  (version B is a start);
- a decision on forage fish, since sand lance is the seal's main prey and its
  calibrated biomass cannot support that (§19).

### Three traps when adding a species to a therMizer model

1. `upgradeTherParams()` re-reads `temp_min` / `temp_max` from
   `given_species_params` when it is called on an object that already has the
   forcing. If the new species' limits were set only in `species_params` they
   silently become NA, and predation and encounter rates turn to NA with them.
2. mizer's `getDiet()` fails for a predator with `interaction_resource` 0
   ("missing value where TRUE/FALSE needed"). Compute consumption from
   `getPredRate()` instead.
3. Calling `upgradeTherParams()` a second time with a constant forcing on an
   already-upgraded object does the same as trap 1; there is no need to
   re-attach if the object already carries the right forcing.

## 21. Dynamic seals revised against the diet data, with exponential growth and harvest

Julia asked for the dynamic seal to be fixed, for its diet to be verified
against the data in ESS_Restructured, and for seals to grow exponentially with
a harvest in 1967-1990. Scripts 4-6 in `dynamic_seal_trial/`; figures
`figures_recalibrated/dynseal_*.png`. Pipeline model files unchanged.

### The diet data in ESS_Restructured

From `00e_digitise_seal_data.r` and `make_S6_seal_diet.R`, all attributed there
to Bowen & Harrison (1994):

- diet by wet weight: sand lance 80.9%, cod 11.0%, silver hake 2.6%, plaice
  1.4%, redfish 1.3%, yellowtail 1.1%, everything else under 0.5%;
- measured mean prey weights: cod 201 g, plaice 132 g, yellowtail 89 g, silver
  hake 66 g, redfish 32 g, sand lance 15 g;
- consumption target: 12 x 170 kg body mass a year, 85% fish = 1.73 t of fish
  per seal.

### Three seal versions against that data, 1990-1995

| | Bowen & Harrison | seal gear | first revised dynamic seal | data-based dynamic seal |
|---|---|---|---|---|
| sand lance, % of fish eaten | 80.9 | 5.1 | 2.3 | 28 |
| cod, % | 11.0 | 15.8 | 57.3 | 24 |
| mean cod eaten, g | 201 | 231 | 858 | 102 |
| mean plaice eaten, g | 132 | 125 | 390 | 114 |
| mean sand lance eaten, g | 15 | 10 | 26 | 7 |
| fish eaten per seal, t a year (target 1.73) | | 1.0 | 1.2 | 0.35 |

- **No version reproduces the diet.** Sand lance is four fifths of the real
  diet and a few percent to a quarter of the modelled one. The model holds
  4-7 kt of sand lance in 1990-95; 62 thousand seals eating 81% sand lance
  would need about 87 kt a year. The multiplied survey has 12,000 kt.
- **The gear matches the measured prey sizes**, as it was built from them.
- **My first revised seal fitted the fish best of anything so far** (cod at
  0.41 of its 1978-81 level, held-out biomass bias x1.12, total fish biomass
  5.6 g/m2 in 2010) **but for the wrong reason**: I had set its preferred prey
  to 200 g, so it ate cod of 858 g on average and cod was 57% of its diet.
  That result should not be used.

### The data-based seal

- Prey size: a grid search found the single kernel that best matches the six
  measured prey weights: preferred prey about 20 g, width 1.5 (log RMSE 0.22).
  Paper 2's kernel (about 15 g) was close to this already.
- Consumption: the model cannot supply the full 1.73 t of fish per seal at
  those prey sizes; the calibration breaks down above roughly 7 kt a year at 15
  thousand seals. The data explain why: 81% of the diet is sand lance, which
  the model lacks. The target was therefore 19.1% of 1.73 t = 0.33 t per seal
  of fish other than sand lance (5 kt at 15 thousand seals), with the rest of
  the seal's food from outside the model.
- Calibrated: 19/19 fish within 2x on biomass, 15/16 on yield. Sand lance and
  spiny dogfish end with `erepro` above 1.

### Seal growth and harvest

Search summaries of DFO and related documents (not the documents themselves)
say: government-sponsored culls in the Gulf and along the eastern shore of
Nova Scotia in 1967-1984; a bounty in 1978-1990; Sable Island "less affected"
and growing exponentially, at roughly 13% a year. No removal table was found.
Likely sources: CSAS Research Document 2023/053 and Lavigueur & Hammill (1993).

Fitted to the digitised counts 1961-2010 with a seal-only model:

| | with harvest 1967-1990 | no harvest |
|---|---|---|
| unharvested growth rate, per year | 0.134 | 0.109 |
| harvest rate, per year | 0.033 | |
| log RMSE against counts | 0.182 | 0.194 |

The harvest version implies about 150 seals removed in 1967, 530 in 1980 and
1,400 in 1990 (13,700 in total). These are fitted, not data, and the counts
barely tell the two versions apart. Exponential growth does give the right
shape (slow, then steep), which the earlier recruitment-capped seal did not.

In the full model the seal tracks the counts to 1990 (40 thousand against 38)
and then lags: 108 against 155 in 2000, 207 against 280 in 2010. Its growth is
slower there than in the seal-only fit.

### Result: a data-consistent seal does not control the fish

| 16 species without multipliers | seal gear | data-based dynamic seal |
|---|---|---|
| biomass 1970-2004: bias, within 2x, median r | x0.90, 12/16, +0.36 | x1.52, 13/16, -0.02 |
| biomass 2005-2010: bias | x0.28 | x2.45 |
| catch 1970-2004: within 2x | 11/15 | 8/15 |
| cod 1994-2004 rel. to 1978-81 (observed 0.13) | 0.64 | 1.08 |
| total fish biomass 2010, g/m2 (survey about 4) | 1.84 | 11.4 |

With prey sizes and consumption that agree with the diet data, seal mortality
on 90-480 g cod reaches only 0.8 per year by 2010 (the gear: 2.6) and 0.05 on
haddock. After the fishery collapses the fish rise to nearly three times the
survey, and cod does not fall.

**So on this evidence seals eating the modelled groundfish at realistic rates
cannot hold the stocks down.** The versions that fit the fish (the gear, and my
first revised seal) do so by taking more, or larger, fish than the diet data
support. That agrees with the conclusion already in the Paper 1 manuscript
notes that seals are a secondary effect, and it points back at the other
candidates: extra adult cod mortality after 1990, and predation by forage fish
on juvenile groundfish, which needs the forage level settled first (§19).

## 22. Time-series optimisation (script 10)

Until now nothing about the fish had been fitted to the time series: 06
calibrates a steady state, and every later test was a hand-set value run forward
and scored. `10.Fit_dynamics_to_time_series.R` adds the fitting step, on the
pipeline model (06's params, seals as a gear).

**Design.**

- Five parameters, each one where a hand-set test had shown the model to be
  wrong (§11, §14, §17): how steeply seal mortality rises above its 1978-81
  level; the scale on which that rise saturates; extra mortality on mature cod
  from 1990; and the share of its catchability the bottom trawl keeps on cod,
  and on haddock, from 1993.
- All five are defined to have no effect in 1978-1981, so 06's steady state is
  untouched.
- Fitted to survey biomass and fishery catch (four fishing gears, not seals)
  for the 16 species without survey multipliers, 1978-2004. 2005-2010 is held
  out, as the protocol requires, and scored afterwards.
- Error is squared log10 difference, averaged within species and variable
  first. `optimParallel` (L-BFGS-B) from three starting points.
- Every run restarts from the 1978 state of 07's projection, which reproduces
  the full run exactly; one evaluation takes about a second. (The slow part of
  earlier runs was `upgradeTherParams()`, not `project()`.)

**Result.** All three starting points converge on the same values.

| parameter | fitted | "no change" |
|---|---|---|
| seal rise multiplier | 0.49 | 1 |
| seal saturation scale | at its upper bound (no saturation) | none |
| extra adult cod mortality from 1990, per year | 0.70 | 0 |
| bottom-trawl catchability kept on cod from 1993 | 0.39 | 1 |
| bottom-trawl catchability kept on haddock from 1993 | 0.19 | 1 |

Mismatch over 1978-2004 (lower is better): 0.625 before, 0.563 after. Putting
each parameter back in turn:

| | mismatch |
|---|---|
| all five fitted | 0.563 |
| without the seal change | 0.611 |
| without extra cod mortality | 0.586 |
| without the haddock moratorium factor | 0.570 |
| without the cod moratorium factor | 0.565 |

- The seal change matters most, and the data want the rise **halved, not
  saturated**. The hand test in §17 had favoured a cap at the 1990 level; the
  fit does not support a saturation parameter at all, so the model has
  effectively four fitted parameters.
- Extra cod mortality of 0.70 a year from 1990 brings total adult cod natural
  mortality to about 0.9. That is high but in line with the assessment view of
  4VsW cod after the collapse (my recollection of the literature, not checked).
- The cod moratorium factor is barely identified: removing it costs 0.002. Once
  cod has extra mortality there is little cod left for the trawl to mis-catch.

**Reading it.**
