## 2. Script 02 — the one to look at first

Two faults, and the second is the dangerous kind.

**`plankton_all` was never built.** The processing chunk returns one *wide*
table per group (`Year` + a column named after the group). The spin-up chunk
expects a single *long* table with `Year / val / variable`. Nothing bridged
them, so the chunk died on its first line and the 1861–2010 plankton files were
never produced. That is why 04's committed `.dat` existed but could not be
regenerated — the inputs were gone.

**`file_label` matched nothing.** It was keyed on the long names
(`Diatoms`, `Diazotrophs`, …) while `variable` carries the short ones
(`Diat`, `Diaz`, …), so every `filter()` returned zero rows.

Fixing only the first fault would have made 02 run **without error** and write
five empty CSVs. I added `stopifnot()` on the key set and a row-count and
contiguous-year check per file so that cannot recur.

## 3. Script 04 — the resource level (the substantive change)

The COBALT-derived resource, measured against the resource
`params_stage1_steady` was calibrated on, over the bins the model actually sees
(`w < w_pp_cutoff`):

| size band | before | after anchoring |
|---|---|---|
| < 0.001 g | ×4.59 | ×0.94 |
| 0.001–1 g | ×5.89 | ×1.21 |
| 1–4.19 g | ×7.23 | ×1.49 |
| 4.19–100 g | ×8.10 | ×1.67 |
| **total** | **×4.96** | **×1.02** |

This is not a fault in your spectrum construction — per-group biomass
conservation is exact to 6e-15, and a semi-chemostat resource tuned to balance
a fish community is not a prediction of plankton standing stock. The problem is
that the fish were calibrated against the lower level, so the ESM level
invalidates the calibration.

**Measured consequence.** A 100-year projection at mean 1861–1960 effort with
the resource held constant:

```
calibrated resource      B(0) 6.52  B(100y)  7.45 g/m2   drift x1.14
GFDL 1861, UNANCHORED    B(0) 6.52  B(100y) 32.74 g/m2   drift x5.02
GFDL 1861, ANCHORED      B(0) 6.52  B(100y) 10.00 g/m2   drift x1.53
```

The unanchored case reproduces what your 05 outputs actually show (36.9 g/m²
at 1961), so the mechanism is confirmed. Note ×1.14 of the residual ×1.53 is
the base model responding to spin-up effort differing from `initial_effort`,
not the resource.

**The fix** is one constant multiplicative factor (×0.206) applied to every
year and every bin, set so the 1978–1981 resource biomass below the cutoff
matches the calibrated resource. Being constant it is additive in log10, so it
cannot touch the slope or the year-to-year variation — both are asserted in the
script. `GFDL_resource_slope.dat` is unchanged; the intercept shifts by the
same constant.

This is a modelling judgment, not a bug fix, which is why it is in its own
commit (`a25138e`) — take it or argue with it independently of the rest.
The alternative would be to recalibrate the fish against the ESM resource.

**Left deliberately alone:** `fit_slope()` fits over every bin with
`dens > 0`, which includes the 55 extension bins it generated itself at exactly
slope `b`. So the self-consistent `b` is partly fitted to its own extrapolation
across 4.4 decades of size. This biases the *slope*, not the level, so it does
not affect the anchor — but it is circular and worth a look. I did not change
it because it would move `b` and that is your call.

The residual ×1.67 in the 4.19–100 g band is your deliberate extension standing
in for prey COBALT does not report. Now the largest remaining discrepancy.

## 5. Script 05 — what was wrong with it

**It has now been run** with `n_sims = 1` on the anchored forcing, and
`Fishmip_output/` and the two `sims_*.RDS` files are regenerated. Section 9
below has the results.

**The cache will silently hand you stale results.** The guard is
`if (file.exists(cache_f) && file.exists(cache_c) && !exists("force_resim"))`,
so it cannot tell that the forcing changed under it — before this run the cached
sims were 46 minutes OLDER than the spectra they were supposedly built from.
Whenever you change params, effort or forcing, **set `force_resim <- TRUE`
before the cache chunk** (deleting the RDS files does not work in a Dropbox
folder — Dropbox restores them within seconds). Worth making the guard compare
file mtimes against its inputs.

**Two objects were used but never defined**, so the script could not reach its
end on any machine:

- `base_dir` was hardcoded to `/Users/ezekieladekoya/...`, and the very next
  line is `stopifnot(dir.exists(base_dir))`. So the whole export section — every
  FishMIP output file — stopped there for anyone else. Now `here::here()`, like
  every chunk before it. (README issue 4 is therefore *not* resolved; I had
  said "largely resolved" from reading the earlier chunks, which was wrong.)
- `catch_ts` is read by the pelagic catch, demersal catch and size-class catch
  sections, but nothing ever built it — `object 'catch_ts' not found`. It is the
  wide form of `yield_ts`, so it is now derived from `yield_ts` where that is
  loaded, which keeps the per-group catch consistent with total catch (tc).

**`n_sims` was 10**, not 1 as the README says. Set to 1 at Julia's request for
a calibration check.

**`biomass_ts.RDS` is generated by a new script.** It was missing. The copies in
the sibling ESS repos are all identical and none is usable: 13 species under raw
upper-case survey names (`AMERICAN PLAICE`, `HERRING(ATLANTIC)`), including
Greenland Halibut, which is not in the model — they fail 05's own check that the
three pelagic species are present by name. The copy in
`Thermizer/August_2025/Ess_Thermizer_data/` is unreadable, possibly corrupt.

So `make_biomass_ts.R` rebuilds it from `LF_Biomass_Abund.csv`, reproducing 05's
own construction step for step (4VsW strata 443–466, 1970–2024, kg→g). Forage
catchability multipliers **are** applied (Herring ×50, Sand Lance ×3000,
Capelin ×200) — Julia's decision. Be aware this means `tpb` is compared against
survey values inflated up to 3000-fold. Those multipliers were tuned to balance
seal predation, not derived as catchability estimates. The script has an
`apply_forage_multipliers` flag if you want raw survey values instead.

**A column-name disagreement worth reconciling.** 05 builds the same survey
table internally around line 419 and renames the value column to `Biomass_Obs`,
but everything after the "Survey data" step (`obs_tcb`, `pel_obs_all`,
`obs_tdb`) sums a column called `Biomass`. So the `readRDS` is load-bearing
rather than redundant, and the two halves of the script disagree. One of them
should change.

## 6. Calibration check (`calibration_check.R`, Julia's script)

Worth recording because it tells you where *not* to look:

- Yields within 7% of target for 16/19 species
- Biomass within 2x for 15/19 — low: White Hake 0.27x, Thorny Skate 0.34x,
  Red Hake 0.42x, Longhorn Sculpin 0.47x
- All `erepro` < 1
- **Stable over 100 years at constant effort: all 19 species within 5%, none
  still moving**

So the catch overshoot is *not* a base calibration failure and not drift in the
calibrated state. That is what pointed at the forcing.

Against observations, before the anchor, modelled catch was high in every
decade — 2.7x (1970s), 3.2x (1980s), 3.8x (1990s), 2.3x (2000s), with spikes at
1981 (17x), 1989 (11x), 1999 (12x). Roughly flat rather than growing, which is
what ruled out progressive drift. Expect ~1.3–1.5x after anchoring, not 1.0.

| variable | unanchored (committed) | anchored (new) | change |
|---|---|---|---|
| tcb 1961 | 36.89 g/m² | 12.35 g/m² | ÷2.87 |
| tcb median | 25.15 | 8.76 | ÷2.87 |

**The ÷3.33 on catch is the point.** Before anchoring, modelled catch ran
2.7–3.8x over observations by decade (§6). The anchor removed almost exactly
that factor, which is the strongest evidence that the resource level was the
cause rather than something that merely correlated with it.

### Agreement with observations, after anchoring

`log10(median obs/sim)`; 0 is perfect, positive means the model is **under**
observations.

| | log10 | ratio | reading |
|---|---|---|---|
| **tc** total catch | **+0.06** | obs ×1.15 | within 15% |
| **tdc** demersal catch | **−0.02** | sim ×1.05 | essentially exact |
| **tdb** demersal biomass | −0.24 | sim ×1.7 | good |
| cd90cm | −0.22 | sim ×1.7 | good |
| cd30to90cm | +0.31 | obs ×2.0 | fair |
| bd30to90cm | +0.28 | obs ×1.9 | fair |
| bd90cm | −0.62 | sim ×4.2 | too many large demersals |
| **tpc** pelagic catch | +0.65 | obs ×4.5 | **under-predicted** |
| tcb total biomass | +0.63 | obs ×4.2 | multiplier artefact, see below |
| tpb pelagic biomass | +2.89 | obs ×776 | multiplier artefact |

Catch is now the best-constrained thing in the model, which is the right outcome
— it is what the effort series and catchabilities were fitted to.

**The two big-looking misfits are not model error.** `obs_exclude` is
`character(0)`, so observed tcb sums all 19 species *including* the forage
catchability multipliers (Herring ×50, Sand Lance ×3000, Capelin ×200). Measured
over the 41 overlapping years:

```
observed tcb, all 19 species      34.16 g/m2   -> obs/sim x4.24
observed tcb, 3 forage excluded    5.04 g/m2   -> obs/sim x0.55  (sim x1.8)
simulated tcb                      8.41 g/m2
the 3 forage species are 85.3% of the observed total
```

So 85% of the "observation" is multiplied sand lance, and tpb's ×776 is just
×3000 diluted. Excluding them puts total biomass at sim ×1.8, consistent with
tdb's ×1.7. **Decide what the multipliers are for before quoting tcb or tpb
against observations** — as it stands those two rows compare the model to a
calibration assumption, not to data.

**Pelagic catch is the real remaining mismatch.** `catch_ts` comes from
`yield_ts`, which has no multipliers at all and which drops Sand Lance and
Capelin, so tpc is essentially herring catch alone — under-predicted ×4.5. That
one is worth chasing.

**The trajectory shape is right.** tcb falls 12.35 → 8.09 g/m² over 1961–2010
and tc falls 2.36 → 0.09, which is the groundfish collapse. The model was not
just too high before, it is now declining for the right reason.

### What is still unverified

- **`n_sims = 1` means there is no ensemble spread**, so every `sim_lower` /
  `sim_upper` band in the figures is a single line and the `tcblog10` /
  `tclog10` "first simulation only" shortcut is invisible. Raise `n_sims` before
  reading anything as an uncertainty range.
- These numbers are medians over the overlapping years, not a fit. Nothing here
  was tuned to them.

## 11. Recalibrating against the COBALT resource

Julia asked for the alternative to the level anchor: build a new therMizer
object, fit the fish to the resource COBALT actually reports, run the long
series, and see whether it still passes through the observed catch and biomass.
Scripts 06, 07 and 08 do that. **It works**: the recalibrated model runs
1861-2010 on the raw COBALT resource with no anchor and stays near the observed
biomass level.

**Two mistakes of mine on the way, recorded so they are not repeated.**

1. An earlier version of this section said this route "cannot work" because
   `steady()` does not find the model's attractor. That was a bug in my script:
   I attached the COBALT forcing array but never set the model's own resource
   state to it, so `steady()` fitted the fish to Stage 1's old resource (a fifth
   of COBALT) and the fish jumped when `project()` swapped the real one in.
2. I then calibrated on 1970-2010 averages. Julia corrected this to
   **1978-1981**, the years the previous calibration used, and that turned out
   to matter enormously (below).

Julia's framing is the one to keep: the steady state is an initialisation that
captures a time-averaged state, `steady()` and `matchBiomasses()` need constant
time-averaged inputs, and the dynamic run is not expected to stay at
equilibrium.

### The calibration (06)

Starts from `params_stage1_steady.RDS`, so species, gears and the interaction
matrix are unchanged and only the resource differs. Three inputs are held
constant at their **1978-1981 mean**:

- the model's resource state, at the unanchored COBALT spectrum (04 now writes
  that file next to the anchored one), with `resource_constant` dynamics;
- temperature, 6.66 / 4.03 C;
- effort, gear by gear (this reproduces Stage 1's `initial_effort`).

The targets in `species_params` are 1978-1981 averages too: per species they
match that window far better than 1970-2010 (7/19 biomass and 9/16 yield within
5%, against 2/19 and 0/18).

`calibrateBiomass()` is deliberately not used, because it rescales the resource
along with the fish. The script asserts at the end that the resource is still
exactly the COBALT spectrum.

```
total biomass        6.491 g/m2
biomass within 2x    19/19 species, median ratio 1.012
yield within 2x      15/16 species, median ratio 1.157
erepro               all below 1 (max 0.383)
```

`matchYield()` errors on this model and is skipped; in an earlier run it
diverged outright, so 06 only keeps a matching step if it improves the fit and
stays admissible.

### The dynamic run (07)

```
1861    6.49 g/m2
1961   10.01      (spin-up change x1.40)
1980    6.41
2010    6.02
```

Scored as Ortega-Cisneros et al. (2025, Earth's Future) step 6 asks -- bias and
correlation of catch and biomass time series -- for the 16 species without
survey multipliers. The paper also says 2005-2010 catch must not be used in
calibration because it is held back for predictive skill; the calibration here
uses 1978-1981 only, so those years are a genuine out-of-sample test.

| | species | median bias (mod/obs) | within 2x | median correlation |
|---|---|---|---|---|
| catch, 1970-2004 | 15 | x1.07 | 9 | +0.54 |
| catch, 2005-2010 (held out) | 11 | x0.74 | 1 | +0.13 |
| biomass, 1970-2004 | 16 | x1.04 | 12 | +0.23 |
| biomass, 2005-2010 (held out) | 16 | x0.90 | 4 | +0.02 |

Summed over those 16 species, modelled annual catch over 1961-2010 is within 1%
of observed (median observed/modelled x1.01). So the level of both biomass and
catch is right, and in-sample catch correlation is reasonable.

**Catch here means fishery catch only.** Seals are a gear in this model, so
`getYield()` counts what seals eat as catch. An earlier version of these
numbers did that and showed catch 2.7x too high in 2005-2010; by then seal
predation is 91% of the "yield" of haddock and 98% for American plaice. 06 and
07 now sum the four fishing gears only, as 05 does. Anything else that calls
`getYield()` on this model needs the same care.

### What does not fit, and why

**1. Cod does not collapse.** Observed cod biomass after 1993 is 13% of its
1978-1981 level; modelled cod keeps rising and is 9.5x observed over 1994-2004.
Modelled cod catch (trawl only) is about 30x observed in that period.

**2. Effort is per gear, the 1993 moratorium was per species.** Bottom-trawl
effort falls 20-45x after 1993, but observed cod landings fall about 200x, to
roughly 430 t a year. Haddock shows the problem cleanly: its modelled biomass is
right (0.83x observed, 1994-2004) but its trawl catch is about 10x too high. A
fleet-level effort series cannot represent a closure on one species. This is
why only 1 of 11 species is within 2x in the held-out years even though the
median bias is modest.

**3. Forage fish go the wrong way.** This is not really a model collapse:

- 1978-1981 is the low point of the (multiplied) survey series for all three.
  Herring is 8.6e9 g then, 6.6e10 before and 3.7e12 by 1996-2010. So the model
  is initialised at the bottom of the observed forage series.
- In the model they then fall further, to 12-15% of the start by 2010 and
  capelin to zero. The Seals gear has catchability 8.26 on all three and seal
  effort rises from 0.024 (1980) to 0.875 (2010), which scales to a seal
  mortality of about 0.2 per year in 1980 and 7 per year in 2010.
- In the survey they rise by two to three orders of magnitude after the early
  1990s.

Points 1 and 3 are probably one problem. On the Scotian Shelf the forage
increase followed the groundfish collapse; a model in which cod never collapses
has no predator release, and meanwhile seal mortality on forage climbs
unchecked. That link is my reading, not something tested here.

Things that would be worth trying, none attempted:

- species-specific effort or catchability after 1993 for the moratorium stocks;
- capping or re-deriving the seal mortality on forage, which was tuned together
  with the survey multipliers (§5);
- error sampling around the initial state, as Julia suggested.

### Which input moves it (08)

Starting from the calibrated state and releasing one input at a time:

```
total biomass, g/m2                 1861    1870    1961    2010
A  all constant                     6.49    6.53    6.51    6.50
B  only effort varies               6.49    8.57    9.95    6.04
C  only temperature varies          6.49    6.57    6.56    6.45
D  only resource varies             6.49    6.53    6.50    6.51
```

The calibrated state holds for 150 years under constant inputs. Resource and
temperature variability barely move it; effort does nearly everything.

**Why 1978-1981 and not a longer average.** The Seals gear:

```
                  Bottom_Trawl  Fixed_Gear  Small_Mesh  Pelagic  Seals
1978-1981             0.879       0.579       0.097      0.442   0.023
spin-up 1861-1960     0.639       0.732       0.047      0.522   0.004
1970-2010 mean        0.563       0.529       0.124      0.511   0.278
```

Calibrating on the 1970-2010 mean balanced the fish against seal mortality that
did not exist in the early years. In that version case B reached 125 g/m2 by
1961 and catch was about 8x observed. Raising reproduction levels did not fix
it (still x7 at 0.99, with `erepro` above 1).

### Where this leaves the two routes

Both now give a model at about the right level for biomass and for total catch
(anchored: total catch within 15%, §9; recalibrated: within 1% for the 16
species without multipliers). The recalibrated one is the more defensible
construction, since the fish are consistent with COBALT's resource by
construction and no anchor is needed. Neither reproduces the cod collapse, the
moratorium or the forage increase, and those are structural rather than a
matter of which resource level is used. The two have not been compared species
by species on identical metrics.

external_species_info <- read.csv("Ess_data/ESS_species_params.csv")

## 13. Reproduction level (resilience to fishing and predation)

Julia's suggestion: the species look too resistant to fishing and predation, so
look at the reproduction level. Tested on the recalibrated model of §11.

**The calibrated levels are indeed very high.** 16 of 19 species sit above 0.9
(herring 0.998, sand lance 0.995, cod 0.956, haddock 0.960); only spiny dogfish
(0.58) and the two skates (0.82, 0.88) are lower. At those values recruitment
is pinned at `R_max` and hardly responds to spawning stock.

**Test.** Each species' level was capped at 0.75, 0.5, 0.25 and 0.1 with
`setBevertonHolt()` (which keeps the calibrated steady state), and the full
1861-2010 series was projected for each. 16 species without multipliers:

| cap | biomass 1970-2004: bias, within 2x | catch 1970-2004: bias, within 2x | cod 1994-2004 relative to 1978-81 |
|---|---|---|---|
| as calibrated | x1.04, 12/16 | x1.07, 9/15 | 1.62 |
| 0.75 | x0.98, 9/16 | x0.94, 8/15 | 1.71 |
| 0.5 | x0.89, 8/16 | x0.76, 8/15 | 1.67 |
| 0.25 | x0.51, 5/16 | x0.54, 6/15 | 1.47 |
| 0.1 | x0.39, 2/16 | x0.43, 5/15 | 1.27 |
| observed | | | 0.13 |

**Lowering the level across the board makes the fit worse, and does not produce
the cod collapse.** Per species, only halibut (best at 0.5) clearly improves;
cod, winter skate and white hake change by 0.01 in log10 RMSE. The species that
were already falling too fast (witch flounder, yellowtail, silver hake, red
hake) fall faster, and the forage fish are wiped out entirely.

**Why it does not help the species that most need it.** The ones that fail to
decline are not shrugging off mortality; in the model they are barely being
killed after about 1990:

- Cod: fishing mortality is about 0.25 per year in 1978-81 and close to zero
  after the moratorium, so modelled cod recovers whatever its reproduction
  level. Observed cod stayed down, which needs extra mortality after 1993, not
  less resilience.
- Thorny skate, winter skate, monkfish: modelled trend is flat (0.00 to -0.01
  log10 per decade against -0.3 to -0.5 observed) at every cap, and their
  modelled catch in 1970-1992 is 4 to 15 times below observed. Their fishing
  mortality is too low, which is a catchability question.

So the reproduction levels are worth revisiting species by species (they are
implausibly close to 1), but on their own they are not what stops the model
tracking the declines. This was a one-off test from a scratch script; it is not
in the repo as a numbered script.

## 14. Adult natural mortality is the missing lever

Follow-up to §13. If the species are too resistant but reproduction level is
not the cause, what is? Breaking mortality down by source for mature fish in
the dynamic run of §11 answers it:

| mature fish, per year | fishing 1980 | fishing 2008 | seals | predation | background | total 2008 |
|---|---|---|---|---|---|---|
| Atlantic Cod | 0.290 | 0.001 | 0.000 | 0.000 | 0.022 | 0.023 |
| Thorny / Winter Skate | 0.013 | 0.000 | 0.000 | 0.000 | 0.025 | 0.025 |
| Monkfish | 0.003 | 0.000 | 0.000 | 0.000 | 0.023 | 0.023 |
| Haddock | 0.188 | 0.001 | 0.007 | 0.010 | 0.041 | 0.058 |

**Adults in this model have almost no natural mortality.** The seal gear takes
no mature cod (its size kernel sits on small fish), predation on adults is nil,
and the background rate is mizer's allometric default (`z0`), which is 0.02-0.04
per year for these species. Once fishing stops, an adult cod dies at about 2% a
year, so the stock cannot stay down. Stock assessments conventionally use 0.2.

Modelled cod fishing mortality is right, incidentally: 0.290 in 1980 against an
observed catch/biomass of 0.316, and 0.215 against 0.240 in 1990.

**Temperature does not touch this.** therMizer 1.1.0 scales predator search
volume (so encounter and predation mortality) and metabolism with temperature.
It has no mortality method, so background mortality is constant, as is fishing
mortality.

### Test: raise background mortality, recalibrate, project

Same procedure as 06 with `ext_mort` raised to at least 0.2 per year, either
for every species or only for five whose modelled trend was flat (cod, white
hake, winter skate, monkfish, pollock). All three calibrate equally well at
steady state (19/19 species within 2x on biomass, 15/16 on yield).

| | as calibrated | M >= 0.2, all | M >= 0.2, five species | observed |
|---|---|---|---|---|
| cod 1994-2004 relative to 1978-81 | 1.62 | 0.69 | 0.68 | 0.13 |
| cod trend, log10 per decade | +0.08 | -0.14 | -0.14 | -0.25 |
| cod correlation with survey | -0.50 | +0.49 | +0.49 | |
| biomass 1970-2004: bias, within 2x | x1.04, 12/16 | x0.80, 12/16 | x0.99, 13/16 | |
| biomass 2005-2010: median log10 RMSE | 0.87 | 0.91 | 0.66 | |
| catch 1970-2004: within 2x | 9/15 | 11/15 | 10/15 | |
| species better / same / worse (RMSE) | | 7 / 4 / 8 | 12 / 7 / 0 | |
| total biomass 2010, g/m2 | 6.02 | 1.76 | 2.66 | |
| max `erepro` | 0.383 | 1.24 (dogfish) | below 1 | |

- Raising it for everything overshoots: plaice, yellowtail, haddock and dogfish
  were already falling too fast and fall faster, and dogfish cannot sustain it.
- Raising it for the five improves 12 species and worsens none. Cod now
  declines after the moratorium and correlates with the survey (+0.49 from
  -0.50); winter skate RMSE goes from 0.66 to 0.37. Species not in the five
  improve too (redfish, yellowtail, witch flounder, sculpin), presumably through
  reduced predation and competition.
- Cod still only falls to 0.68 of its 1978-81 level against 0.13 observed, and
  monkfish and thorny skate barely move. A constant 0.2 is not enough for cod,
  which fits the assessment view that its natural mortality rose after 1990.
- The forage fish are unchanged: still falling under seal mortality while the
  survey rises.

**Caveats.** The five species were chosen by looking at the fit, so this is a
demonstration that the lever works, not an independent test. The value 0.2 is
the textbook default, not an ESS estimate. Proper next step: species-specific
natural mortality from the assessments, and for cod a mortality that rises
after 1990. These were scratch runs; nothing in 06 or the saved params was
changed.
